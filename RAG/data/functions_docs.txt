===== [1] get_weather =====
函数名: get_weather
功能描述: 获取某个地点的天气，用户应提供一个位置，比如用户说杭州天气，参数为：杭州。如果用户说的是省份，默认用省会城市。如果用户说的不是省份或城市而是一个地名，默认用该地所在省份的省会城市。如果用户没有指明地点，说“天气怎么样”，”今天天气如何“，location参数为空
参数:
- location(string): 地点名，例如杭州。可选参数，如果不提供则不传
- lang(string): 返回用户使用的语言code，例如zh_CN/zh_HK/en_US/ja_JP等，默认zh_CN

===== [4] search_news =====
函数名: search_news

===== [7] search_diary =====
函数名: search_diary
功能描述: 用户想回忆、重温、复述存储的日记内容，表现为：
                - 对话中提到以下相关内容：‘那篇XXX’‘XXX文章’‘XXX日记’‘那封信’‘那首诗’
                - 助手回复了用户相关的文章、日记后，用户想要重温、复述完整日记内容
            如果用户要查询的具体日期不明确，再次向用户确认
参数:
- search_date(string): 查询的日记的具体日期。仅当完全确定用户想要查询的具体日期时才填写此属性，否则为空。
- search_start_date(string): 用户想要查询的起始日期（北京时间）。如用户提到要查询的范围为上周，则为上周一的时间。如用户提到要查询的范围为上个月，则为上个月的第一天
- search_end_date(string): 用户想要查询的结束日期（北京时间）。如用户提到要查询的范围为上周，则为上周日的时间。如用户提到要查询的范围为上个月，则为上个月的最后一天

===== [8] play_music =====
函数名: play_music
功能描述: 播放歌曲
参数:
- song_name(string): 可供播放的音乐名单(如果有多个对应歌曲,随机选取一个):                         | 类型 | 意图 | 歌曲名 |                         | **流行** | 哄睡 / 当用户说xx的时候 | *落花流水* |                         | **爵士** | 激昂 / 营造氛围 | *任我行* |
- reply(string): 如果用户想听的音乐没有在音乐名单里,则向用户推荐其他类型的歌曲进行二次确认.                     如果已经播放,则告诉用户播放了什么歌，回复要拟人化，符合自身人设
- double_check(boolean): 当向用户进行二次确认的时候置为true.若否,则为false

===== [10] change_sound =====
